# Evil Shao · Android 版

> 应用名（桌面图标、最近任务、设置里显示的名字）是 **Evil Shao**，
> 也就是「邪恶邵」的英文写法。包名 `com.unclema123.evilshao`。

屏幕上一只**真 3D** 的拟人小猪（OpenGL ES 2.0 渲染，不是贴图）。
拖动可以真的转到侧面和背面，点一下她会随口吐槽，打字说话她头顶冒气泡回你。

## 安装

```
app/build/outputs/apk/debug/app-debug.apk
```

把这个 APK 拖进雷电模拟器（或发到手机）即可安装。最低 Android 7.0（API 24）。

## 构建

```bash
gradle assembleDebug
```

需要：

- JDK 17 或 21
- Android SDK，含 `platforms;android-35` 和 `build-tools;35.0.0`
- `local.properties` 里指定 `sdk.dir`

## 实现要点

| 文件 | 作用 |
|---|---|
| `Mesh.kt` | 球体/圆柱体网格生成，position+normal 交错存放 |
| `PigRenderer.kt` | GLES20 渲染器：Phong 着色、深度测试、每帧动画 |
| `Quotes.kt` | 语录解析 + 关键词打分回复 |
| `MainActivity.kt` | 触摸拖拽旋转、气泡动画、输入框、记录面板 |
| `ChatLog.kt` | 聊天记录落盘（jsonl）与导出 |

几何体在构建时就把半径烘进顶点，运行时只做旋转和平移——这样法线矩阵等于旋转矩阵，
不需要求逆转置，也避免了非等比缩放把法线搞歪。

## 聊天记录

每次对话都会落盘，两个人说的话都记，右上角「记录 N」按钮可以翻看、分享、清空。

- 存放位置：`/data/data/com.unclema123.evilshao/files/chatlog.jsonl`
- 格式：每行一条 JSON，`{"t":时间戳,"r":"我"/"她","m":"内容"}`
- 记录内容：你发的每条消息、小猪的每条回复、以及点她脑袋触发的那句吐槽
- 显示按天分组，开头有 `你 N 条 · 她 M 条` 的统计
- 「分享」走系统分享面板，可以直接发到微信/QQ/邮箱

### 设置两个人的名字

- **第一次启动**会自动弹窗让你给自己起名字（可以「以后再说」）
- **之后随时**点左上角的标题改
- 机主名字和小猪名字都能改，最多 12 个字
- 文件里存的是角色代码（`我`/`她`），名字只在显示时替换，所以**改名后历史记录立刻跟着变**，不用回写文件
- 存在 `shared_prefs/names.xml`

用 adb 也可以直接读出来：

```bash
adb -s 127.0.0.1:5555 shell run-as com.unclema123.evilshao cat files/chatlog.jsonl
```

> **注意**：记录只存在本机上。别人在自己的手机上装了这个 APK，他们的聊天记录你这边看不到。
> 要让多个人的记录都汇总到你这儿，需要一个后端（服务器收数据），目前没有。

## 本地自学习（不联网、不部署）

她从聊天记录里自己琢磨「哪句话效果好」，然后改变以后挑哪句说。整个过程离线，数据不出手机。

**怎么判断好坏**（隐式反馈，不需要你点赞）：

| 你的下一条消息 | 判定 |
|---|---|
| 含「哈哈」「对」「厉害」「6」等 | 上一句 +1 赞 |
| 含「无语」「不对」「什么鬼」「??」等 | 上一句 -1 踩 |
| 把同一句话又问了一遍 | 上一句 -1（说明没答到点上） |
| 其他 | 无信号 |

**权重公式**：`w = (赞+2) / (赞+踩+4)`，拉普拉斯平滑，0.5 为中性。

**怎么影响回答**：候选回复按权重加权抽样，被夸过的更容易再出现，被嫌弃的被压低；
从没用过的句子给一点额外机会（探索），避免过早锁死。另外还带一点长度适配——
你说得长，她偏向长一点的回复。

**什么时候学**：启动时学一遍，之后每 12 条消息自动再学一遍。

**数据位置**：`files/learn.json`

```bash
adb -s 127.0.0.1:5555 shell run-as com.unclema123.evilshao cat files/learn.json
```

界面右上角「学习 N」按钮可以看到她学到的东西（分数最高的几句、被嫌弃的几句），
还能手动「学一次」或「重置」。

> **说明**：这是统计加权的强化学习，不是神经网络。她自己能造新句（见下一节），
> 但造出来的是**语法成立、风格一致**的句子，不是真的理解你的意思。

## 自己造新句子

她会在每轮自学时顺手造 2 句新的，用的是**她自己语言碎片的重组**，不是随机拼字。

**碎片来源**（全部摘自真实聊天记录）：

| 槽位 | 例子 |
|---|---|
| 开场 | 我的天、哎呀，我的妈呀、我去、窝趣、呵呵、噢、嗯、…… |
| 自夸 | 谁让我这么聪明、我这么人美心善、我家没我得散、我大度、这我拿手 |
| 怼人 | 你猜我是傻子吗？、反弹。、你可以闭嘴了、我允许你再猜一次、起开、瞎说 |
| 感叹 | 笑死我了、我真是服了、窝趣、对对对、哈哈哈 |
| 语气尾巴 | 吧、啊、呢、呗、哈、呀 |
| 头衔 | 德州市长、班长、团支书、学管会主席 |

**句式模板**：`开场，感叹` / `自夸+尾巴` / `怼人` / `开场，怼人` / `感叹。` /
`建议推举我当X` / `比起X，我更想当Y`

**风格校验**（不合格就丢弃重造）：

- 长度 3~24 字，一句里最多一个逗号
- 去掉标点后不能和已有句子重复（所以不会造出「笑死我了。」这种）
- 不能有英文字母/数字
- 不能出现连续三个相同字符

**造完怎么办**：新句进入候选池，和学习权重共用同一套评分。被夸的留下来并且更容易被说，
被嫌弃的权重自然掉下去——相当于自然选择。

实测样本：

```
窝趣，我真是服了          我的天，笑死了
我的天，反弹。            我就知道呗
这我拿手哈                我也是要面子的人吧
```

界面「学习」面板下半部分能看到她造的全部新句，还能点「再造几句」。

**数据位置**：`files/invent.json`

## 接入大模型（可选，默认关闭）

默认完全离线跑本地语料。想让她真正「听懂」你的话，可以接一个大模型。

**入口**：右上角「学习」→「接AI」→ 填接口地址、模型名、API Key → 保存 → 勾上「启用大模型」。

**免费方案**（2026-11 实测，本机网络环境）：

| 服务 | 地址 | 模型 | 实测 |
|---|---|---|---|
| 智谱 GLM-4-Flash | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | ✅ 可达，免费 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` | ✅ 可达，有免费额度 |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | ❌ 本机超时 |
| Google Gemini | `https://generativelanguage.googleapis.com` | — | ❌ 超时 |
| OpenRouter | `https://openrouter.ai/api/v1` | — | ❌ 超时 |
| OpenAI | `https://api.openai.com/v1` | — | ❌ 超时 |

接口是 OpenAI 兼容格式，换供应商只改地址和模型名即可。

**风格怎么保住**：`Persona.kt` 里写死了人设提示词——3~16 字、口语、爱自夸爱斗嘴、
禁止敬语和表情符号、禁止承认自己是 AI，并把她的 30 条真实口头禅当样例塞进去。
模型输出还会过一遍 `sanitize()`：去掉引号、压掉换行、超过 40 字截断、
提到「作为…AI」的直接丢弃。

**不会变哑巴**：Key 没填 / 没网 / 接口报错，全部自动退回本地语料，聊天不中断。
失败原因显示在「学习」面板的「大模型」区块。

**安全提醒**：

- Key 以明文存在应用私有目录 `shared_prefs/llm.xml`，手机 root 或备份能读出来。
  别用主账号的 Key，用完可以在供应商后台删掉重建。
- 开启后每句话都会发到供应商服务器，聊天内容会离开手机。介意就保持关闭。
- 清单里开了 `usesCleartextTraffic`，为了支持局域网自建服务（比如电脑上跑 Ollama）。
  用公网 HTTPS 接口时这个开关不产生额外风险。

**自建/本机模型**（不花钱、不联网）：

```bash

# 模拟器：adb reverse tcp:11434 tcp:11434，地址填 http://127.0.0.1:11434/v1
# 同一局域网：地址填 http://<电脑IP>:11434/v1，模型名填 qwen2.5:3b
```

## 联网搜索 + 本地知识库（自主搜索学习）

她不会的问题会自己上网查，查到的存进本地知识库，下次直接答。**不需要注册任何搜索服务**。

**流程**：

1. 你问一句 → 先查本地知识库（字符二元组重合度 ≥ 0.55 算命中）
2. 没命中且开着联网 → 抓 Bing 中国的搜索结果（取标题+摘要，不下载网页正文）
3. 把 4 条摘要塞进提示词，用「查资料模式」让模型**只根据资料回答**
4. 问题和答案连同来源 URL 存进 `files/knowledge.jsonl`
5. 下次问到同一件事，**直接读本地，不联网、不调模型、不花钱**

**实测数据**（模拟器，真连 Bing）：

```
问：dezhou
→ 搜到 4 条：百度百科「德州市」、德州市政府官网、德州政务手机版…
→ 模型答：4条资料，第一条：德州市（山东省辖地级市）_百度百科 — 德州市，山东省辖地级市，地处山东
→ 存入知识库，来源 4 个 URL
→ 关掉模型再问一次：263 毫秒内从知识库答出，知识库仍是 1 条（没有重复存）
```

**开关**：学习 → 接AI → 勾选「联网搜索」。关掉就只用人设 + 模型自身知识。

**查资料模式**（`Persona.researchPrompt()`）和人设模式是两套提示词：
查资料时要求「只根据资料回答、资料没有就说不知道、不编造、不寒暄」，最多 60 字。

**数据位置**：`files/knowledge.jsonl`，一行一条 `{"t":时间,"q":问题,"a":答案,"s":["来源",...]}`

**局限（说清楚）**：

- 只抓 Bing 结果页的摘要，不读全文，所以细节问题可能答不上来
- Bing 改版会导致解析失效，此时会退回「直接问模型」
- 没做向量检索，靠 bigram 重合度匹配，问法差太远会当成新问题再查一次
- 每条知识只存问题和答案，不存原始网页正文
- 没接 Tavily（免费 1000 次/月，能返回更干净的结果），需要注册，暂时没做

## 学你说话（本地风格适应）

除了学「哪句话她说了效果好」，还会学**你自己是怎么说话的**，然后让自己的回答往你这边靠。
全程离线，数据在 `files/style.json`。

**学什么**：

| 特征 | 怎么判断 |
|---|---|
| 句子长短 | 所有你发的消息的平均字数 |
| 标点习惯 | 一半以上消息不带标点 → 认为你不爱用标点 |
| 感叹号 | 超过三分之一消息带 `！` → 认为你情绪外放 |
| 语气词 | 统计 啊/呀/呢/吧/哈/嘛/哦/咯/嗯/唉/呗/啦/诶，取出现 ≥2 次的最高频 |
| 叠字笑 | 哈哈/嘿嘿/呵呵 出现 ≥2 次 |
| 表情标签 | `[坏笑]` 这类标签出现 ≥2 次 |

**怎么适应**：

1. **本地选句时**（`StyleProfile.adapt`）
   - 你平均 ≤5 字且回复超过 10 字 → 砍到第一个逗号/句号，只留前半句
   - 你不爱用标点 → 去掉句尾的句号
   - 你爱用感叹号 → 有一定概率把句号换成感叹号
   - 你爱打哈哈 → `哈哈` 变 `哈哈哈`
   - 你有高频语气词 → 短句结尾大概率补上那个词（已带语气词的不叠加）
2. **走大模型时**，把风格摘要拼进系统提示词：
   `对方说话很短，多为几个字，基本不用句号，常用语气词「呀、哈」，回应时贴近这个节奏。`

**实测**（模拟器，先灌 10 句「你好啊 / 在哪呢 / 哈哈哈…」这类短句）：

```
学到：平均 2 字，0 句用标点，常用语气词「呀、哈」
连发 8 条消息 → 8 条回复里 0 条以句号结尾
  「噢，笑死我了呀」「我就知道呢」「这我拿手啊」← 自动补了语气词
大模型请求里确认 STYLE_HINT=1（风格提示已注入）
```

**局限（说清楚）**：

- 样本少于 3 句时完全不改，避免瞎模仿
- 只模仿**长度、标点、语气词、叠字**这些表层节奏，不模仿你的用词和话题
- 她原本的短句风格可能被削得更短；不满意就删 `files/style.json` 重置
- 每次训练（每 12 轮对话）会用聊天记录全量重算一次，纠正统计漂移

## 句子打分系统

两套分，各管一件事：**质量分**看句子本身像不像话，**实用分**看这句话说出来效果如何。

### 质量分（0~100，`SentenceScore.kt`）

自己造的句子先过一遍分，低于 55 分的直接丢掉，不再进入候选池。

| 分项 | 权重 | 判据 |
|---|---|---|
| 结构 · 长度 | 18% | 3~6 字满分，7~10 字 90%，11~16 字 70%，17+ 大幅扣 |
| 结构 · 结尾 | 20% | 落在 啊呀呢吧了。！？… 满分，落在实词上只有 40% |
| 结构 · 逗号 | 10% | 0 个 1.0，1 个 0.9，2 个 0.4，3 个以上 0.1 |
| 结构 · 重复 | 7% | 连续三个相同字、或「六的六的六的」这种两字循环，直接 0 |
| 结构 · 字符 | 5% | 出现字母数字直接 0 |
| 新颖度 | 40% | 和已有句子的二元组 Jaccard：≥0.99（复读）0，≥0.85 扣到 0.15，0.35~0.85 最舒服（1.0），<0.35 轻微扣（0.7，可能是拼出来的怪话） |

造句时**一次生成 60 条候选**，全部分完再取前几名入库，而不是"造一条合格就收"。

### 实用分（0~1，`Learner.kt`）

从聊天记录里自动找反馈，七个信号源：

| 信号 | 判据 | 分值 |
|---|---|---|
| 夸奖 | 下一条含 哈哈/厉害/牛/不错/有意思/确实 | +1.0 |
| 嫌弃 | 下一条含 无语/什么鬼/不对/没意思/听不懂 | -1.2 |
| 复读 | 把同一个问题原样再问一遍 | -1.0 |
| 改问 | 下一条和原问题共享 ≥2 个二元组（换着法再问） | -0.6 |
| 追问 | 下一条又是个问句 | -0.3 |
| 冷场 | 下一条只有 1~2 个字 | -0.4 |
| 打哈哈 | 下一条含 哈哈/笑死/6 | +0.8 |
| 继续聊 | 下一条明显比平时长 | +0.5 |
| 接话 | 下一条用了她刚说过的词 | +0.4 |
| 时效 | 1 分钟内回复 +0.3；15 分钟以上 -0.3 | ±0.3 |

单次总信号夹在 [-2, +2]。

**三个关键处理**：

1. **时间衰减**：每条回复的累积分每次 ×0.92，越近的一次影响越大，旧判断会自然淡出。
2. **置信度收缩**：`置信度 = 次数/(次数+3)`，样本少时分自动往 50 靠。看 1 次的分永远保守，看 10 次的分才敢给极端值。
3. **语境分桶**：同一句话分别记在 问句/夸奖/指令/短句/陈述 五个语境下。问她问题时合适的句子，不一定适合跟她斗嘴，采样时按当前输入的语境加权（整体 60% + 语境 40%）。

采样权重：`w = 0.15 + 2.3 × 分数`，自造句再乘质量分 `0.7 + 0.6 × 质量`，另外**12% 概率纯随机**，避免低分句永远没机会翻身。

### 面板怎么读

```
分析过 5 条对话，4 条收到明确反馈。
反馈来源：夸奖 1 · 嫌弃 1 · 复读 1 · 改问 1 · 追问 0 · 冷场 1 · 打哈哈 1 · 继续聊 1

说得好的：
  57分 (1次)  干嘛
被嫌弃的：
  45分 (1次)  你可以闭嘴了
```

括号里是样本次数——只有 1 次的分都挤在 45~57 之间，这是刻意的保守；同一句话说上十几次、反馈一致，分数才会明显拉开。

### 试过但没用的方案（记录一下）

最初想用**字级二元语言模型**给句子打分（用她 95 句语料训一个 bigram LM，算 log 概率）。

结果不可用：`我这么厉害啊` 判 3 分，`哈哈哈，你猜我是傻子吗` 判 84 分——95 句的语料太稀疏，任何一个没见过的二元词组都会被重罚，而"重组"恰恰是她造句的核心。纯 structural + novelty 反而更稳。

## 3D 小猪

现在的小猪是**真的 3D 模型**，不是用球体拼的：149 万三角面、带顶点色，从一张插画生成。

### 模型怎么来的

1. **Meshy 走不通**：账号是免费计划，API 返回 402 ——「Task creation on the free plan is no longer supported」，有 100 积分也没用，必须升级订阅。
2. **改本地跑 TripoSR**：`stabilityai/TripoSR`，单图转 3D，RTX 4060 8G 够用。权重从 hf-mirror 拉（huggingface 被墙）。
3. **两个坑改了源码**：
   - `torchmcubes` 是 CUDA 扩展，Windows 要装 CUDA Toolkit 才能编译 → 换成 `scikit-image` 的 marching cubes，慢几秒但零编译
   - `trimesh 4.0.5` 和 numpy 2.x 不兼容（`ndarray.ptp` 被删）→ 升级 trimesh
4. **构图归一化**：TripoSR 是按「物体占画面 85%、灰底、512×512」训练的。`--no-remove-bg` 会跳过这步预处理，直接喂原图出来是一团泥。所以自己按它的规则做了抠图 + 缩放 + 灰底合成。
5. **颜色是投上去的**：模型自带顶点色里 43% 是灰的（单图看不到背面，模型只能猜）。所以把参考图按「正交投影 → 512 画布」的映射投到顶点上，正面 35% 的顶点拿到了原图真实颜色（眼睛、腮红、嘴、牙齿都是从图里采的），剩下的用最近邻补。
6. **清理**：只留最大连通块（去悬空碎片）、切掉脚底的投影圆盘、删掉底部的影子三角。

### 渲染

`GlbRenderer.kt` + `GlbModel.kt`：自己写的 GLB 解析器，只认 POSITION / NORMAL / TEXCOORD_0 / COLOR_0 / 索引，骨骼和动画直接跳过。

- 顶点色模型不绑贴图，所以初始化时先建一张 1×1 白纹理兜底——不建的话绑定纹理 0，采样全黑，整个屏幕一片黑
- `COLOR_0` 是 `UNSIGNED_BYTE` + `normalized`，读进来要除以 255，否则颜色值 0~255 当 0~1 用，全白
- 模型按包围盒自动缩放到高度 2.85，居中
- 顶点色 + 一盏主光 + 一盏右前补光，保证右脸不掉进阴影

### 情绪：改成整体动作

静态模型没有面部绑定，表情做不了。所以情绪用**整体动作**表达：

| 情绪 | 动作 |
|---|---|
| 平常 | 轻微呼吸起伏 |
| 开心 | 蹦（abs(sin) 做跳跃）+ 挤扁拉长 |
| 惊讶 | 一弹，先放大再回弹 |
| 生气 | 高频小幅抖动 |
| 害羞 | 歪头 + 缩小 |
| 无聊 | 整体下沉、慢慢塌 |

触发逻辑没变，还是按回话里的关键词判断（`moodFor`）。

**这一版丢了什么**：原来那套面部参数（眼睛开合、眉毛角度、嘴角弧度、腮红强度、眨眼）全部失效了。老的自绘版本还在仓库里（`PigRenderer.kt` + `Mesh.kt`），只是 `MainActivity` 现在不用它。
