# 小猪 NPC · 和邵珠佳聊天

一个单文件网页小程序：左边一只拟人化的小猪，右边是聊天界面。她说的话来自「语录库」，
你可以随时往里加她自己的原话。

## 怎么用

双击 `打开小猪.bat`，或直接双击 `index.html`（用浏览器打开即可，不需要联网、不需要装环境）。

- **Enter** 发送，**Shift + Enter** 换行
- 右上角 **清空对话**：只清聊天记录，不动语录
- 右上角 **语录管理**：添加 / 删除回复，导入导出

## 回复是怎么选出来的

按优先级：

1. **关键词规则** —— 你的消息里出现某个关键词，就从对应的回复里随机抽一条。
   例如 `吃饭,饿 => 你吃了吗，别饿着`。
2. **特色回复** —— 没命中关键词时，多数情况从「她的口头禅 / 招牌句式」里随机抽，
   这是这个角色的主要气质来源。
3. **兜底回复** —— 剩下的情况走这里，用来接住完全没头绪的话。

连着重复同一句会被避开（最近用过的 4 条不重复）。

## 语录管理里怎么加

三块内容，每块下面都有一个输入框，**一行一条**，点「添加」即可：

| 区块 | 格式 | 例子 |
| --- | --- | --- |
| 特色回复 | 直接写原话 | `你要不要这么离谱` |
| 关键词规则 | `关键词,关键词 => 回复` | `吃饭,饿 => 你吃了吗` |
| 兜底回复 | 直接写原话 | `嗯？` |

关键词用逗号分隔（中文逗号、顿号也行），回复想给多条时用 `|` 分隔，会随机选。

## 数据存在哪

存在浏览器的 localStorage 里 —— 换浏览器、清缓存、开无痕窗口都会丢。
**重要语录记得点「导出 JSON」备份**，以后用「导入 JSON」就能恢复。

## 当前状态

内置语料来自**2026-11-14 ~ 11-16 三天的聊天记录**（邵珠佳在聊天里显示为 Whisper）。
共 29 条口头禅、19 组关键词规则、6 条兜底。

### 她的说话特征（写语料时照着这个调）

1. **短句连发** —— 一句话一条消息，几乎不写长段落，节奏很碎。
2. **自夸当幽默** ——「朕」「谁让我这么聪明」「谢谢，我就是当代福尔摩斯」「我家没我得散」。
   不是真自恋，是拿自己开涮逗你笑。
3. **惊讶三连** ——「我的天」「哎呀，我的妈呀」「我去」「窝趣」，出现频率极高。
4. **宏大幻想梗** ——「建议推举我当德州市长」「比起德州市长，我更想取代特朗普」「等我穿越回古代我就有一技之长了」。
5. **小学生式斗嘴** ——「反弹。」「你猜我是傻子吗？」「你！！！」，幼稚得理直气壮。
6. **装无语** —— 单独一条「……」，她最常用的冷处理。
7. **反讽吐槽** ——「你居然能找出这理由来」「你还挺有自知之明」「谁跟你一样」。
8. **生病时的虚弱自嘲** ——「是不是末世要来了所以提前给我的惩罚」「一个坚强的女人……后面不记得了」。
9. **命令式玩笑** ——「快快快，撤回」「我允许你再猜一次」「你可以闭嘴了」，凶得没有攻击性。
10. **帮亲不帮理** —— 讲完道理立刻「都怪他」「要不是因为你比较善良的话，谁搭理他啊」。
11. **爱记账** ——「那行，那我记住了」「你是不是该谢谢我？」「噢，我还得谢谢你呗」。
12. 句尾爱带「嘞」「吧」，也爱中英混搭（「No no no」「我说话从来不搞抽象 OK？」）。
13. 常用表情标记：`[坏笑]`、`[动画表情]`、`[大哭]`、`[微笑]`，直接写进语料就行。
